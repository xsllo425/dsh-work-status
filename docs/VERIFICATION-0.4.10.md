# dsh-work-status 0.4.10 功能对应复核

日期：2026-10-26。用户选择暂不重启 DSH。

## 问题与改动
1. 原来丢弃 ops_bash 的 description，再用命令正则猜测目的，可能把 printf 格式串当搜索目标。现在独立保留 description，命令优先显示该说明；展开显示原工具名与说明。
2. 原来不同脚本简写成“内联脚本”后被合并，造成左侧多次调用无法逐条对应，合并时长也包含间隔。现在一次调用一行；最新三条与历史折叠布局保持。
3. 原来任一工具结果到达就把 phase 改成 thinking，即使并行工具尚在运行。现在剩余 toolOpen > 0 时保持 tool。
4. 保留 targetKind，区分路径等目标类型和 tool/context 类别。

## 生效与限制
- 源码版本 0.4.10，stateVersion 17。需要后续经用户允许重启 DSH，使宿主加载并按新版本重放旧 checkpoint。
- 前端可热加载，但旧宿主在重启前不提供新增 description/targetKind，暂时仍可能使用旧摘要。
- 左侧保留已完成工具记录、面板显示下一步思考，本身不代表错误；应按 callId 和结果时序判断。
